# Google Play ストア掲載情報(ドラフト)

Play Console の「ストアの設定」にそのまま貼り付けられる文言ドラフト。文字数はPlayの上限
(アプリ名30字・簡単な説明80字・詳しい説明4000字)を確認済み。LPサイト
(`readygo-speak-api/site/phrase/index.html`)の訴求をそのまま踏襲している。

## アプリ名(30字以内)

```
ReadyGo Phrase：句動詞・熟語・単語
```
(24字)

## 簡単な説明(80字以内)

```
知ってる単語なのに聞き取れない。句動詞・熟語・単語をめくって覚えるTOEICレベル別アプリ
```
(45字)

## 詳しい説明(4000字以内)

```
"pull over"。単語はどっちも知ってるのに、意味だけが出てこない。

「pull(引く)」も「over(超えて)」も知っている単語なのに、"pull over"と言われた瞬間、
意味が消える。ネイティブは、その単語が簡単だからこそ「知っていて当然」だと思って、
句動詞や熟語を会話の中で当たり前のように使ってきます。

ReadyGo Phrase は、カードをめくりながらそのギャップに慣れていく、句動詞・熟語・単語アプリです。

■ 見て、めくって、覚える
表現を見て、意味を考えて、めくって判定する。それを繰り返すだけの、シンプルなフラッシュカード
学習です。意味が表示されるまでの3秒間、「これ、知ってるはずなのに」と思い出そうとする、
その一瞬が記憶に残ります。

1. 見る - 句動詞・熟語・単語がひとつ、カードに表示されます
2. 考える - 3秒間、意味を頭の中で予想します(設定で変更可)
3. めくる - 覚えていたら左に、わからなかったら右にめくります。意味が出る前にめくってもOK
4. くり返す - 「わからない」を選んだ表現だけが、復習モードにもう一度出てきます

■ TOEICスコアでレベルを選べる
句動詞・熟語の難しさは「フォーマルさ」ではなく「どれだけ知られているか」で決まります。
だからレベルは文法基準ではなく、TOEIC換算の3段階(600点未満・600〜700点・800〜900点)。
その日の気分やスコアに合わせて選び直せます。

■ 収録内容(随時追加予定)
・句動詞(Phrasal Verb): turn on、put up with、come up with など
・熟語(Idiom): under the weather、bite the bullet、cost an arm and a leg など
・単語(Word): 留学・ワーホリ準備に欠かせない日常〜ビジネス語彙

■ はじめるのに、準備はいりません
・ログイン不要 - アカウント登録なしで、匿名のまま学習履歴が残ります
・レベルは毎回選べる - 起動するたびにレベル選択画面が出ます
・わからなかった分だけ復習 - 「わからない」を選んだ表現だけが復習モードのキューに残ります
・発音の音声つき - 表現・例文をタップすると、ネイティブの発音が聞けます

瞬間英作文アプリ「ReadyGo Speak」(画面を見ない「ながら学習」)の姉妹アプリです。
Speak が耳と口を鍛えるなら、Phrase は目で見て「あれ、なんだっけ」のギャップに慣れる練習。
知ってる単語で、聞き取れるようになろう。
```

## データセーフティ申告(Play Console「データセーフティ」フォーム用の事実整理)

実装(`readygo-speak-api`・`lib/`)を根拠に整理。最終的な申告内容・文言はTK確認のうえPlay Console上で入力する。

| 収集するデータ | 内容 | 必須/任意 | 用途 | 共有 |
|---|---|---|---|---|
| 匿名の識別子 | `POST /api/v1/users`で発行されるランダムトークン(メール・氏名等は一切紐づかない、`app/models/user.rb`参照) | 必須(アプリ機能に必要) | 学習履歴の同期・復習キュー生成 | 第三者と共有しない |
| アプリの使用状況 | レベル・モード・フリップ結果(覚えている/わからない)・所要時間(`phrase_study_flips`等) | 必須(アプリ機能に必要) | 復習モードの出題・履歴画面の表示 | 第三者と共有しない |
| 広告ID | AdMob(`google_mobile_ads`)がバナー広告配信のため取得 | 任意(ATT/UMPの同意次第。拒否時はパーソナライズなし広告) | 広告表示・計測 | Google(AdMob)と共有 |

- **個人を特定する情報(氏名・メール・電話番号・住所等)は収集しない**(アカウント登録・ログイン機能自体が無い)
- 位置情報・連絡先・写真等のデバイス権限は要求しない
- データはHTTPS通信のみ(`api.readygo-english.space`)。暗号化通信の申告は「はい」
- ユーザーはアプリ内から学習データの削除を要求する手段を現状持たない
  (匿名トークンを端末に保存しているのみで、削除APIは未実装。**要検討**: データ削除手段の要否)
